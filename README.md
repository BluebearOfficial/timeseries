# 时间序列探索器

一个从 Excel 导入、存储到分析可视化的时间序列工具。

最初只是为了看一份 75 年的日均温数据，后来扩展到步数、活动等多个时间序列。

## 它能做什么

- **网页上传 Excel**（`date | value` 两列），自动写入数据库
- 支持多个时间序列（温度、步数、活动……）
- 丰富的分析功能：

| 类别 | 功能 |
|---|---|
| 基础 | 按类型查看原始数据 |
| 趋势 | 累积平均、峰值月、滑动平均、季节天数 |
| 分布 | 星期分布、月度分布、大幅偏高天数 |
| 对比 | 温度 vs 步数、温度 vs 活动、相关性分析 |
| 单点 | 某月趋势、某月每日、单日查询、排行榜 |
| 工具 | 导出当前图为 PNG |

## 从数据里发现的

这不是一个"管理系统"，是一个"探索工具"。用它的过程里，发现了一些有意思的事：

**1. 变暖推进线**

按月份看"日均温 ≥ 某阈值"的天数，能看出"变暖从最热的月份向外扩散"：

| 月份 | 最后一次"0 天 ≥30" |
|---|---|
| 7 月 | 从未有过 |
| 8 月 | 2000 年 |
| 9 月 | 2020 年 |
| 10 月 | 2021 年首次破零 |

**2. 夏天变长、冬天变短**

以"日均温 ≥25°C 算夏天、<12°C 算冬天"为标准：

- 夏天：从 70-100 天，涨到 2024 年的 **140 天**
- 冬天：从 90-125 天，降到 2023 年的 **60 天**
- "剪刀差"在 2020 年后加速打开

**3. 步数是倒 U 形**

不同温度下的平均步数：

| 温度 | 平均步数 |
|---|---|
| 0-5°C | 6500 |
| **15-20°C** | **9900**（最高） |
| 35-40°C | 6400 |

**"太冷太热都不出门，温和时走得多"——这也解释了为什么"温度 vs 步数"的相关系数接近 0（皮尔逊只测线性关系）。**

**4. 样本量陷阱**

"0-5°C 活动率最低"看起来是个结论，但只有 **5 天**样本——1 天变动就翻倍。图上标注天数后，可信度一目了然。

## 技术栈

- **后端**：Node.js + Express
- **数据库**：SQLite（better-sqlite3）
- **Excel 解析**：xlsx
- **文件上传**：multer
- **前端**：原生 HTML/CSS/JS
- **图表**：Chart.js

## 运行

### 1. 安装依赖

```bash
npm install
```

### 2. 准备数据

把你的 Excel 放到 `data/` 目录，格式为两列：`date | value`。

`date` 建议用 `YYYY-MM-DD` 格式。

### 3. 导入数据（二选一）

**方式 A：命令行导入**

编辑 `import.js` 里的文件列表，然后：

```bash
node import.js
```

**方式 B：网页上传**

启动后端后，在网页上选文件、选类型、点上传。

### 4. 启动

```bash
node server.js
```

或：

```bash
npm start
```

访问 `http://localhost:3000`。
